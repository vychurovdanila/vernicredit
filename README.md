# Vernicredit (Верни Кредит)

B2C-сервис возврата страховок и переплат по кредитам (автокредиты, потребкредиты, кредитные карты). 
Клиент проходит бесплатный аудит, получает пошаговый план и шаблоны писем в банк, действует сам. 
Мы сопровождаем, ведем переписку (дрип-шаблоны) и берем комиссию только после возврата денег клиенту.

## Технологический стек
- **Frontend:** React (Vite) + TypeScript + Tailwind CSS 3.4
- **Backend:** Python (FastAPI) + SQLAlchemy + PostgreSQL (SQLite для локальной разработки)
- **Инфраструктура:** GitHub, VPS

## Структура проекта
- `backend/` — FastAPI приложение, модели, миграции (Alembic)
- `frontend/` — React приложение (в разработке)
- `chat.md` — история принятия бизнес-решений (ADR)
- `.clineignore` — правила для AI-ассистента Cline
